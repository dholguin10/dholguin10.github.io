# How I created my E-Portfolio
## Introduction
In this section I am going to guide you threw how I made my e-portfolio step by step to highlight my understanding and knowledge
## Creating the Repository
I started with creating a GitHub account and we went through a step by step process of how to create a repository in class. I created repositry as a place to house all of the work that we have done in class to showcases my knowledge and understanding of the concepts we have learned 
## Setting up GitHub Pages 
After creating my repository, I configured GitHub Pages so that the repository would be displayed as a website. GitHub Pages automatically publishes the content stored in the repository and provides a web address where the site can be viewed online. Once GitHub Pages was enabled, I was able to access and edit my e-portfolio through my GitHub repository and see the updates on the live website.
## Editing The Homepage
When editing I decided to use my resume as a good starting base for what to include onto my website. I did this because as I continue to work and gain new skills I am able to update it as I go along with making it relevant to what I am applying for. I also added a picture of me that is professional looking as a way for someone to see me. 
## Customizing the Website 
When customizing the website I added specific subsections and bolded them to highlight a change or a new part of the website. I also bulleted different skills or experiences to not only showcase that I understand how to navigate GitHub markdown, but also make it easier to navigate through the website
